## 本轮完成内容

### 1. 消除本地备份与 JSON 导出中的同步明文凭据泄漏（`src/js/storage.js` & `src/js/import-export.js`）
- **`createBackupSnapshot(data)`（`src/js/storage.js`）**：克隆快照数据时强制将 `settings.syncServerToken` 与 `settings.syncE2eePassphrase` 置空，避免在自动/手动本地备份列表中保留明文 Token 与 E2EE 密钥。
- **`createImportExport`（`src/js/import-export.js`）**：
  - 新增 `sanitizeDataForExport(source)`，清除根 `settings` 与历史 `backups[*].data.settings` 中的 `syncServerToken` 与 `syncE2eePassphrase`；`exportJsonToClipboard()` 与 `openManualExportModal()` 统一输出脱敏副本且不污染内存运行态。
  - 新增 `preserveLocalSyncSecrets(targetSettings, currentSettings)`，在 `openBackupModal()` 恢复历史备份与 `openImportModal()`（`mode === "replace"`）导入脱敏 JSON 时自动保留本机当前有效 `syncServerToken` 与 `syncE2eePassphrase`。

### 2. 对齐剪贴板同步包导出的 `docId` 与平台标识（`src/js/import-export.js`）
- 修复 `#btnSyncExportBundle` 此前总是生成随机 `createDocId()` 与手写 UA 判断的问题，统一复用 `getSyncStatus().docId || createDocId()` 与 `detectExtensionPlatform()`，与文件导出（`#btnSyncExportFile`）行为一致。

### 3. 补齐 `rotateE2eePassphrase` 的 `stale_epoch` 自动重拉重试（`src/js/sync_engine.js`）
- 在 `rotateE2eePassphrase` 推送循环的 `precondition_failed` 分支同步采纳服务端返回 `epoch`，并新增 `stale_epoch`（`409`）自动恢复分支：收到 `stale_epoch` 时同步新 `epoch`、重新 `httpPullState` 并以旧口令解密合并（含空库 `no_remote` 兜底）后自动重试新口令加密推送。

### 4. 消除 Firefox 持久化 E2E 落盘竞态抖动（`tests/firefox-persistence/runner.js`）
- `seed` 阶段改字号至 `13` 后显式等待新字号与含 `fontSize === 22` 的自动备份快照双双落盘，并留出 `350ms` IndexedDB WAL 刷盘稳定窗口；同时增强 `verify` 阶段诊断报错信息。
