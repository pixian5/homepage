# 默认背景改纯色 + 旧数据迁移（2026-10-25 06:41）

版本：26.0.4。

## 改动

| 项 | 旧 | 新 |
|---|---|---|
| `DEFAULT_SETTINGS.backgroundType` | `bing` | `color` |
| `app.js` 背景兜底 | `"bing"` | `"color"` |
| 数据 schema 版本 | 1 | 2 |
| 迁移函数 | 无 | `1 → 2`：`backgroundType === "bing"` 改为 `"color"` |

新增用户从第一次打开起就不会请求 Bing 壁纸；老用户在下一次打开新标签页时自动迁移。

### 迁移的取舍

旧版本把 `bing` 当成默认值写进了数据，无法区分“用户主动选的壁纸”和“从来没改过”。
按项目约定（开发测试版，可合理重构），统一改为纯色；**用户仍可在设置里重新选择 Bing 壁纸**，
选过之后 `backgroundType` 会再次变成 `bing`，不会被反复改回。

### 迁移会落盘

`loadData()` 现在会比较迁移前后的 `schemaVersion`，发生迁移时立刻写回本地存储，
避免每次打开都重复迁移。

## 实测

| 检查 | 结果 |
|---|---|
| `defaultData()` | `schemaVersion=2`、`backgroundType=color` |
| 旧数据迁移 | 1 → 2，`bing` → `color` |
| 迁移幂等 | 迁移两次结果一致 |
| 显式选择的其他背景 | `gradient` 保持不变 |
| 迁移不修改入参 | 通过 |
| 真实共享文件 | 启动 Safari 后 `schemaVersion 2`、`backgroundType color`，45 节点、8 备份无变化 |
| 页面实际背景 | `background-image: none`，纯色 `rgb(232,17,17)`（沿用用户此前的纯色值） |
| 页面网络请求 | 壁纸相关请求 0 条 |
| 单元测试 | 193/193（新增 2 条迁移用例） |

迁移前数据已备份到 `.test-backups/bg-default-20261025-061557/homepage-data.before.json`。
