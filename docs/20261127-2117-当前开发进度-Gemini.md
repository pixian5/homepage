## 本轮完成内容

### 1. 根因复现与链路拆解
在 `27.4.9` 消除 CSS `:hover` 边缘平移自激后，基于用户真实 Chrome 扩展本地数据（`syncEnabled: true`，含 33 个书签卡片与 2 条已删墓碑节点）在无头 Chrome 复现时，观测到 `#grid` 仍在后台约 12 次/秒反复重建（每 40 帧内 `detached: 33~40`、`gridRebuild: 238~306`、`imgSrc: 231~297`、`attr: 427~547`），使鼠标悬停时的卡片与图标不停销毁重建并闪跳：
1. **同步投影集合顺序不稳定**：Chrome `chrome.storage.local`（LevelDB）反序列化 `homepage_data.nodes` 按键名字母序排列（旧墓碑 `itm_178602...`/`itm_178654...` 在前），而 `mergeHomepage()` 此前按「先存活后墓碑」拼装 `nodes`，导致云端与本地 `toSyncDocument()` 产出的 `nodes` 顺序不一致；`isContentEqualToRemote()` 直接对比未规范化的 `contentHash` 永远返回 `false`，引发无休止拉取与合并。
2. **`sync_engine` 本地落盘缺少自写回声抑制**：[app.js](file:///Users/x/code/homepage/src/js/app.js) 中 `saveLocal` 直接调用 `saveData(next, false)` 且未设置 `persistenceCoordinator.setSuppressStorageUntil(...)`，`saveData` 写入新 `lastUpdated` 后立即触发本页 `storageListener` → `reloadFromStorage()` → `loadData()`（恢复 LevelDB 字母序）→ `pullNow("storage_reload")` → `applyRemoteDoc()` → `onMerged() -> render()` 的永久死循环。
3. **启动首拉无变更仍重绘**：[sync-startup-coordinator.js](file:///Users/x/code/homepage/src/js/sync-startup-coordinator.js) 在 `pull.unchanged === true` 且发件箱未触发推送时仍无条件调用 `render()`。

### 2. 修复实现
- [sync_projection.js](file:///Users/x/code/homepage/src/js/sync_projection.js)：
  - 新增确定性码点排序比较器 `compareSyncKey` 与纯对象键递归排序 `sortPlainObjectKeys`，在 `toSyncDocument()` 中对 `groups`（按 `id`）、`nodes`（按 `id`）、`placements`（按 `parentKind`/`parentId`/`index`/`nodeId`）做确定性排序；
  - 保留 `hashSyncDocument(doc)` 原逻辑以兼容服务端 [sync-server.mjs](file:///Users/x/code/homepage/scripts/sync-server.mjs) 与恢复脚本校验，新增并导出 `canonicalizeSyncDocument(doc)` 对齐旧客户端已上传快照的语义比较。
- [sync_engine.js](file:///Users/x/code/homepage/src/js/sync_engine.js)：`isContentEqualToRemote()` 先走原始 `contentHash` 快路径，不等时再对比 `hashSyncDocument(canonicalizeSyncDocument(localDoc)) === hashSyncDocument(canonicalizeSyncDocument(remoteDoc))`，兼容历史未排序云端文档并立即短路退出。
- [sync_merge.js](file:///Users/x/code/homepage/src/js/sync_merge.js)：`mergeHomepage()` 按确定性排序遍历 `nodeIds`，固定 `mergedNodes` 键序。
- [app.js](file:///Users/x/code/homepage/src/js/app.js)：为 `initSyncEngine.saveLocal` 与 `init()` 去重/语言初始化落盘前后补齐 `persistenceCoordinator?.setSuppressStorageUntil?.(Date.now() + STORAGE_SUPPRESS_MS * 4)` 抑制自身回声，并在 `onMerged` 中同步调用 `syncBackupBaseline(data)`。
- [sync-startup-coordinator.js](file:///Users/x/code/homepage/src/js/sync-startup-coordinator.js)：仅在首拉非 `unchanged`、执行了 `pushNow` 或 `flushOutbox` 真正发送出队项时调用 `render?.()`。
