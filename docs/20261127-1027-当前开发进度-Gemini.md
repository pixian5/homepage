## 本轮完成内容

### 1. 类型契约对齐与回归校验（`src/js/types.js` & `tests/types-contract.test.js`）
- 全面重写 `src/js/types.js` 的 JSDoc `@typedef`，使其与 `src/js/storage.js` 中 `DEFAULT_SETTINGS`、`Group`、`ItemNode`、`FolderNode`、`BackupSnapshot`（`{ id, ts, data }`）、`HomepageData` 和 `SyncStatus` 运行时结构完全一致，清理陈旧失效字段。
- 新增 `tests/types-contract.test.js` 契约测试：自动校验 `defaultSettings()` 的每个键都声明在 `Settings` 类型定义中，且过时键不再残留。

### 2. 拆出同步冲突解决器（`src/js/sync_conflict_resolver.js` & `src/js/sync_engine.js`）
- 新增 IIFE 模块 `src/js/sync_conflict_resolver.js`（导出 `HomepageSyncConflictResolver.createSyncConflictResolver`），将 `resolveDocConflict` 与 `getPendingConflict` 从 `src/js/sync_engine.js` 中独立解耦，缩减约 170 行核心引擎体积。
- 同步在 `scripts/firefox-modules.json` 与 `src/sw.js` 中将 `sync_conflict_resolver.js` 注册在 `sync_engine.js` 之前，确保 Firefox bundle 拓扑与 PWA 预缓存清单一致。

### 3. 全拼与首字母双模拼音搜索升级（`src/js/pinyin-match.js` & `tests/pinyin-match.test.js`）
- 新增结构化常用汉字全拼字典 `COMMON_CHAR_PINYIN_MAP`，并导出 `getCharPinyins(char)` 与 `getPinyinFullVariants(text, maxVariants = 8)`；未收录字符自动回退至 `getCharInitials(char)`。
- 提取内部共用展开辅助函数 `expandCharVariants`，在 `matchesSearchQuery` 中同时匹配首字母变体与全拼变体（连续子串与有序子序列，避免跨音节无序误匹配）。
- 扩展 `tests/pinyin-match.test.js`，覆盖全拼与多音字全拼检索（如 `maoyan` / `maoyanshuqian` -> `冒烟书签`，`chongqing` / `zhongqing` -> `重庆地图`，`shezhi` -> `设置`，`baidu` -> `百度`）。

### 4. Popup UI 与窄屏 PWA 响应式加固（`src/popup.js`、`tests/popup-ui.test.js`、`src/styles.css`）
- 在 `src/popup.js` 导出 `applyPopupI18n`、`initPopup`、`renderPopupBookmarks` 与 `showPopupError` 供纯 Node DOM mock 测试直接调用，新增 `tests/popup-ui.test.js` 覆盖多语言切换、文件夹/书签树渲染、折叠开关切换与错误状态展示。
- 在 `src/styles.css` 补充 `@media (max-width: 768px)` 与 `@media (max-width: 520px)` 媒体查询规则，改善窄屏分栏/PWA 窗口下的边栏、搜索框与网格布局适配。
