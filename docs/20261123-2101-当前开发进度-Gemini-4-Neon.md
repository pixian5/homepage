# 27.2.2：触摸测试提速 40 倍并拆出同步设置面板与设备认证模块

## 问题与实现

1. **复核 27.2.0 & 27.2.1 并修复触摸取消用例（`src/js/touch-drag-manager.js`、`tests/touch-drag-manager.test.js`）**：
   - `createTouchDragManager(deps)` 新增可选定时参数 `tileContextMenuMs`、`tileLongPressMs`、`groupLongPressMs`、`clickSuppressMs`（生产环境沿用 1000ms / 3000ms / 260ms / 400ms 默认值，零改动）。
   - `tests/touch-drag-manager.test.js` 改用短定时配置，单文件耗时由 **20.3s 降至 0.44s**（全量单元测试总耗时由 24.0s 降至 **12.3s**）。
   - 复核中发现历史测试 `"cancels the long press when the finger moves beyond the threshold"` 未实际绑定 `document` 监听与派发 `touchmove`，本轮一并修复为真实滑动取消断言。

2. **拆分 `src/js/settings-controller.js` → `src/js/sync-settings-panel.js`**：
   - 将同步冲突处理弹窗（`openSyncConflictModal`）、表单同步字段即时读取（`applySyncSettingsFromForm`）、同步状态行渲染（`refreshSyncStatusLine`）、协同设备健康度与注销/激活仪表盘（`refreshSyncDevices` / `renderSyncDevicesList` / `setSyncDeviceRetired`）及按钮事件装配（`bindButtons`）抽离至独立 IIFE 模块 `sync-settings-panel.js`（475 行）。
   - `settings-controller.js` 从 1,160 行降至 **705 行**，对外返回签名完全保持兼容。

3. **拆分 `src/js/sync_engine.js` → `src/js/sync_device_auth.js`**：
   - 将传输配置/鉴权头组装（`getTransportConfig` / `getTransportAuth`）、设备独立凭据单飞自动配对（`ensureDevicePairing`）、401 失配清理（`dropStaleDeviceCredentials`）及 403 设备退役熔断入口（`markDeviceRetired`）抽离至独立 IIFE 模块 `sync_device_auth.js`（160 行）。
   - 同步更新 `scripts/firefox-modules.json` 拓扑注册与 `src/sw.js` PWA 预缓存清单，保证三端及纯 Web 离线模式下拓扑与加载顺序一致。
