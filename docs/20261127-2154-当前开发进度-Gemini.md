## 本轮完成内容

针对 `27.5.0` 之后系统性排查出的多标签页存储回声放大器、同步元数据回写震荡、无防抖提示条刷新、未受抑制的写盘竞态与潜在墓碑 TTL 失配问题，完成全链路修复与回归测试：

### 1. 写入来源标记与切断多标签页 `reloadFromStorage()` 链式放大风暴
- [persistence-coordinator.js](file:///Users/x/code/homepage/src/js/persistence-coordinator.js)：在 `persistData()` 写盘前写入 `_syncMeta.lastWriteSource = "newtab_edit"`（写盘失败回滚时恢复原值/删除），并在 `finally` 中重新续期 `suppressStorageUntil`（与 `sync_engine` 的 `saveLocal` 对齐，防止慢写盘导致抑制窗提前失效）。
- [sync_engine.js](file:///Users/x/code/homepage/src/js/sync_engine.js) 与 [sync_device_auth.js](file:///Users/x/code/homepage/src/js/sync_device_auth.js)：`persistMergedLocalState()` 打标 `"sync_merge"`；`pushNowImpl()` / `rotateE2eePassphrase()` 记录 `_syncMeta.revision` 与 `ensureDevicePairing()` / `dropStaleDeviceCredentials()` 落盘凭据时打标 `"sync_meta"`。
- [background.js](file:///Users/x/code/homepage/src/js/background.js) 与 [popup-batch-save.js](file:///Users/x/code/homepage/src/js/popup-batch-save.js)：后台侧栏加书签与 Popup 单页/批量保存统一写入 `_syncMeta.lastWriteSource = "external"`。
- [app-reload-coordinator.js](file:///Users/x/code/homepage/src/js/app-reload-coordinator.js)：
  - 新增 `isVisibleHomepageStateEqual(prev, next)` 与跨标签页 10 秒 TTL `localStorage` 认领器 `defaultClaimExternalReload(lastUpdated)`；
  - 对 `newtab_edit` / `sync_merge` / `sync_meta` 来源，其它标签页在 `reloadFromStorage()` 时不再重复触发 `pullNow("storage_reload")`、`schedulePush()`、`processPendingIconFetches()` 或 `consumeSaveToast()`；
  - 对 `sync_meta` 纯元数据/设备凭据回写，若可见状态一致则跳过整页 `render()` 与覆盖警告 Toast；
  - 仅首个认领 `external`（`popup` / `background`）写入的标签页执行同步补拉、补推与图标/提示消费，避免 N 个标签页同时并发竞争与触发 HTTP 412。
- [icon-manager.js](file:///Users/x/code/homepage/src/js/icon-manager.js)：`fetchFaviconInBackground()` 在成功与失败两处调用 `persistData()` 前均校检 `target.iconPending` 仍为真，避免多路并发重复落盘。

### 2. `onSyncKeysChanged` 防抖与存储监听/状态清理优化
- [storage-listener.js](file:///Users/x/code/homepage/src/js/storage-listener.js) & [app.js](file:///Users/x/code/homepage/src/js/app.js)：新增可配置 `syncKeysDelayMs` 独立防抖定时器（主入口配置为 `200ms`，并在 `dispose()` 中清理），合并单轮拉/推周期内的连续 `homepage_sync_state` / `homepage_sync_outbox` 变更通知，避免 N 标签页同步提示条高频重复读取存储。
- [sync_state_store.js](file:///Users/x/code/homepage/src/js/sync_state_store.js)：`clearOutboxRecord()` 先比对去重前后条目数，队列本就为空时不再空写 `storage.local.set`。

### 3. 补齐未受抑制的本地写入与竞态防护
- [settings-controller.js](file:///Users/x/code/homepage/src/js/settings-controller.js) & [app.js](file:///Users/x/code/homepage/src/js/app.js)：`btnClearData` 清空前与 `finally` 均调用 `suppressStorage()`，防止 `clearData(false)` 删键触发 `storage.onChanged`（`newValue: undefined`）提前拉起 `reloadFromStorage()`。
- [storage.js](file:///Users/x/code/homepage/src/js/storage.js) & [app.js](file:///Users/x/code/homepage/src/js/app.js)：`loadData({ onBeforeInternalWrite })` 在 Safari 稳定存储恢复、空初始化及 schema/根模型迁移 3 个内部写盘分支写入前回调开启抑制窗。

### 4. 跨标签页拉取去重、冲突采纳远端去冗余推与统一墓碑 TTL 口径
- [sync_engine.js](file:///Users/x/code/homepage/src/js/sync_engine.js)：`installVisibilitySync()` 与 `startSyncInterval()` 发起 `pullNow` 前先 `loadState()` 校验共享 `homepage_sync_state.lastPullAt`，处于冷却窗口内时跳过重复拉取。
- [sync_conflict_resolver.js](file:///Users/x/code/homepage/src/js/sync_conflict_resolver.js)：选择 `choice === "remote"` 且未启用 E2EE、内容与远端完全一致时，跳过多余的 `pushNowImpl("resolve_remote")`。
- [sync_projection.js](file:///Users/x/code/homepage/src/js/sync_projection.js)、[sync_merge.js](file:///Users/x/code/homepage/src/js/sync_merge.js)、[sync_engine.js](file:///Users/x/code/homepage/src/js/sync_engine.js)：统一 `toSyncDocument`、`canonicalizeSyncDocument(doc, { tombstoneCutoff })`、`syncContentFingerprint`、`mergeHomepage` 与 `isContentEqualToRemote` 的 `tombstoneNow` / `tombstoneTtlMs` 口径，消除有限 TTL 场景下可能发生的「拉取-重插过期墓碑-清理墓碑」乒乓隐患。
