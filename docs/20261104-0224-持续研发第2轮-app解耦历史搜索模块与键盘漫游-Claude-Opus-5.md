## 一、巨石模块 app.js 解耦

**app.js：3435 → 3264 行（净 -171 行；删除 275 行旧实现，新增 104 行接线代码）**，拆出两个高内聚模块：

### `src/js/history-manager.js`（300 行，新模块）

- `createHistoryManager(deps)` 依赖注入（t/toast/数据与容器访问/持久化/弹窗等 18 项，与 settings-controller 同风格）；
- `fetchRecentHistory()`：`chrome.history.search` / `browser.history.search` 双形态兼容（回调 + Promise），7 天窗口、限 24 条、URL 规范化去重；`visit-history.js` 自建记录兜底合并（Safari）；status 状态机（ok/error/missing/fallback）与拆出前完全一致；
- `renderHistoryCards(browserItems, visitItems, limit)`：**纯函数**视图模型（去重/倒序/截断），独立单测；
- `addHistoryToShortcuts(node, groupId)`：协议白名单校验 → `createItemNode` → 位置追加 → 持久化 + 渲染 + 后台图标抓取；
- `addHistoryToDefaultGroup` / `openAddToGroupModal` / `getPreferredGroupIdForNewItem`（固定分组 > 上次活跃分组 > 首分组，历史分组不可为目标）。

### `src/js/search-manager.js`（144 行，新模块）

- `createSearchManager(deps)`：`handleInput`（实时拼音过滤当前网格，复用 pinyin-match）、`submitSearch`（Enter/按钮 → 当前搜索引擎新标签；空查询聚焦搜索框）、`handleEscape`（清空 + 恢复全量卡片，**新增能力**）、`bind`（幂等绑定，重复调用先解绑）；
- `buildSearchUrl` / `filterTilesByQuery` 纯函数导出，独立单测；
- 搜索框 focus 时历史分组自动刷新（经 `onFocus` 回调注入）。

### 架构门禁

两个新模块已在 `scripts/firefox-modules.json` 按依赖拓扑注册（search-manager 紧随 pinyin-match；history-manager 紧随 visit-history），`bundle-firefox` 拓扑校验 + 经典脚本语法断言通过，产物含全部新代码。

## 二、全键盘网格漫游与 A11y

- **几何核心**下沉 `drag-geometry.js` 新纯函数 `nextGridFocusIndex({index, columns, count, key})`：四方向 + Home/End，**不循环**（越界保持原位），无焦点时方向键/Home 落首项、End 落末项；
- app.js 全局 keydown（`settings.keyboardNav` 开启时）升级：方向键只在**可见卡片**间漫游（被搜索过滤隐藏的 `display:none` 卡片跳过）；**Home/End** 聚焦首/末卡片；**Delete/Backspace** 删除聚焦卡片（复用带撤销的 `deleteNodes`，历史分组禁删保护沿用），删除后焦点移到同位置下一张不中断漫游；
- **ARIA**：网格容器 `role="grid"`（newtab.html 主网格与文件夹覆盖层两处）；每张卡片 `role="gridcell"` + `aria-label`（文件夹带计数后缀语义）；
- **焦点高亮**：`.tile:focus / :focus-visible / .is-focused` 蓝色轮廓样式（styles.css）。
