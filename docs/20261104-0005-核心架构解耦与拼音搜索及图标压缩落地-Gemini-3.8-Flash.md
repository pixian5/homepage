## 二、 关键架构变更与模块设计

### 2.1 模态对话框管理器（`src/js/modal-manager.js`）

- **抽离职责**：`parseModalHtml`, `findModalDefaultActionButton`, `bindModalEnterToDefaultAction`, `createModalManager`（包含通用 `openModal`, `closeModal`, `openAddModal`, `openEditModal` 及异步抓取与表单校验）。
- **解耦契约**：通过纯依赖注入（Options）接收主环境的 DOM 容器、国际化函数 `t`、Toast 提示、容器助手函数与生命周期回调，消除了对外层全局变量的隐式依赖。
- **效果**：`src/js/app.js` 单文件由 3902 行下降至 3424 行，主文件结构大幅度清爽化。

### 2.2 上下文右键菜单管理器（`src/js/context-menu.js`）

- **抽离职责**：`positionMenuAt`（视口边缘自动贴靠与防溢出算法）、`createContextMenuManager`（卡片菜单、文件夹菜单、历史卡片菜单、分组菜单的构建与动作派发）。
- **防溢出测试**：涵盖标准视口、贴右边界、贴下边界与负值坐标修正测试。

### 2.3 零依赖中文拼音首字母模糊搜索（`src/js/pinyin-match.js`）

- **原理**：利用 GB2312 汉字区间与 `String.prototype.localeCompare(boundary, 'zh-CN')` 的字母边界判定：
  - “百度” $\to$ `bd`
  - “哔哩哔哩” $\to$ `blbl`
  - “GitHub中文社区” $\to$ `githubzwsq`
- **体验提升**：用户在顶部搜索框输入 `bl` 即可秒级高亮出“哔哩哔哩”，输入 `jd` 即可匹配“京东”，无需频繁切换中英文输入法。

### 2.4 图标上传 Canvas 自动压缩管道（`src/js/icons.js`）

- **函数**：`compressImageFileToDataUrl(file, maxDimension = 128, quality = 0.85)`
- **管道流**：
  1. SVG 矢量图直接保留原有 DataURL，保持无损清晰；
  2. 位图通过离屏 Canvas 按原始宽高比缩放至边长 $\le 128\text{px}$；
  3. 优先编码为 `image/webp`，不支持时平滑降级为 `image/png`；
  4. 测试与无 DOM 环境走原声 FileReader 兜底。

### 2.5 Firefox 构建链依赖拓扑门禁（`scripts/bundle-firefox.mjs`）

- **拓扑检查算法**：
  - 自动扫描参与打平的全部模块源码；
  - 提取 `import ... from "./xxx.js"` 语句；
  - 严密校验被依赖模块是否已在 `firefox-modules.json` 中登记且排在当前模块之前；
  - 本次接入后，立刻发现并纠正了历史遗留的 `sync_policy.js` 依赖排位滞后问题。
