## 一、抽离 `src/js/selection-manager.js`（批量模式与多选）

**app.js：2558 → 2247 行（-311）**，两新模块合计约 480 行。

- `createSelectionManager(deps)` 完整封装批量选择交互：
  - 模式：`isBatchModeActive()` / `toggleBatchMode(force)`（退出时清集合与框选框）；`executeBatchDelete()` 三态语义——未激活先激活（toast 提示）、激活但空选直接退出、有选中调用**支持撤销的 `deleteNodes`** 后退出；历史分组禁批量（警告 toast）；
  - 集合：`toggleTileSelection(id, index, range)`（Shift 范围选，锚点语义与原实现逐字一致）、`selectTile`、`selectAll`、`getSelectedIds`、`has`、`retainOnly`（数据整包替换后过滤失效 ID）、`clearSelection`；
  - 框选：`bindBoxSelectEvents()`——mousedown 网格空白启动、6px 位移阈值判定、矩形与可见卡片几何相交命中、结束后 `consumeBlankClickSuppress()` 吞掉下一次误触点击；
  - 控件：`updateControls()`（全选按钮可见性 / 批量按钮文案切换）、`updateStyles()`（卡片选中态）；`bindBatchButtons()` / `bindBlankClickClear()`；
- app.js 移除 `selectionMode/selectedIds/lastSelectedIndex/boxSelecting/selectionBox/selectionStart/isDraggingBox/suppressBlankClick` 全部散落状态与 8 个函数、3 组监听；render 尾部与 tile 渲染分支全部改经 manager 接口。

## 二、抽离 `src/js/theme-manager.js`（视觉外观管线）

- `createThemeManager(deps)`：
  - `applyTheme(mode)`：light/dark 写 `data-theme`；system 跟随 `prefers-color-scheme` 并**幂等挂载一次**变化监听（原实现监听器挂在模块顶层，抽离后内聚为 `bindSystemThemeListener`）；
  - `applyFontSize(fontSize)`：`--base-font` / `--tile-font` 双变量；`applyDensity()`：`--grid-gap` + 卡片尺寸兜底（非法密度回退 standard）；
  - `applyBackground`（`loadBackground` 状态机）：bing（按语言取图、成功 toast、**缓存命中静默**、彻底失败回退纯色+错误 toast）、color/gradient/custom 分支；`setBackground` 保持防注入（仅放行 `url()` / CSS 函数 / 关键字）；`applyBackgroundOverlay`（仅图片类背景生效、0.6 封顶）；
  - `refreshBackgroundIfChanged()`：背景签名（类型/颜色/渐变/自定义图长度+前缀/遮罩/语言）未变不重跑；同页并发合并为一次请求；
- app.js 移除 9 个函数与 `densityMap/_bgOverlayMap`（死代码顺带删除）、`appliedBackgroundSignature` 状态；settings-controller 注入改经 `themeMgr.*` 转发。
- **冒烟抓到一处真实回归**：renderGrid 内还有一处 `densityMap` 引用被我删常量后遗漏——浏览器冒烟立即暴露 `ReferenceError`，补回局部密度表后全绿（这正是坚持真实浏览器验证的价值）。
