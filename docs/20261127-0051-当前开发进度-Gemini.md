## 本轮完成内容

### 1. 加固自建 HTTP 同步服务（`scripts/sync-server.mjs`）
保持单文件零外部依赖部署特性（兼容 `.github/workflows/deploy-sync-server.yml` 单文件覆盖部署与 `.snapshots/` 无感知增量备份），落地四项安全与容灾增强：
- **常量时间 Bearer 主令牌比对**：启动时对 `TOKEN` 计算 SHA-256，鉴权时对传入凭据做 SHA-256 后使用 `crypto.timingSafeEqual` 进行常量时间比对，避免时序侧信道风险。
- **滑动窗口限流（`RATE_LIMIT_RPM` / `PAIR_RATE_LIMIT_RPM`）**：
  - 按客户端来源 IP 维护 60 秒滑动窗口：当 `/v1/*` 连续鉴权失败（401）达到 `RATE_LIMIT_RPM`（默认 `60`，设 `0` 可关闭）或 `POST /v1/sync/pair` 超过 `PAIR_RATE_LIMIT_RPM`（默认同 `RATE_LIMIT_RPM`）时，返回 `429 { error: "rate_limited", retryAfter }` 与标准 `Retry-After` 响应头。
  - 来源 IP 默认读取 `req.socket.remoteAddress`，仅在显式配置 `TRUST_PROXY=1` 时解析 `x-forwarded-for`，防止未经过反代时伪造请求头绕过限流；`/health` 不受限流影响。
- **可选 CORS 白名单（`ALLOWED_ORIGINS`）**：
  - 未配置 `ALLOWED_ORIGINS` 时保持 `Access-Control-Allow-Origin: *` 向后兼容；
  - 配置逗号分隔白名单后，放行的 `Origin` 按请求回显 `Access-Control-Allow-Origin` 与 `Vary: Origin`，非白名单 `Origin` 在 `OPTIONS` 预检返回 `403 origin_not_allowed` 且普通响应不附带 CORS 允许头，统一作用于全路由。
- **写前滚动历史快照（`MAX_HISTORY_SNAPSHOTS`）**：
  - 每次 `saveToDisk` 原子覆盖 `DATA_FILE` 前，将当前旧版状态文件复制到同目录 `.snapshots/<DATA_FILE>.<timestamp>-<seq>.json`，并自动裁剪超出 `MAX_HISTORY_SNAPSHOTS`（默认 `5`，设 `0` 可关闭）的早期快照。
