# 项目经验库

本目录从 `docs/` 的分析、排查和验证记录中提炼可复用经验。  
历史文档保留当时的版本和上下文；本目录只保留当前仍适用的原则、检查清单和操作方式。

## 分类

- [同步可靠性](同步可靠性.md)：冲突、ETag、outbox、墓碑和 epoch。
- [Safari 构建与安装](Safari构建与安装.md)：Xcode 工程格式、签名、注册和数据保护。
- [浏览器测试与发布](浏览器测试与发布.md)：单元测试、浏览器冒烟、CI 和发布门禁。
- [生产备份与恢复](生产备份与恢复.md)：备份、恢复、回滚、回收和故障演练。

## 使用原则

1. 先看本目录的当前经验，再查 `docs/` 中的原始证据。
2. 涉及生产数据、墓碑回收或安装替换时，先备份并使用 dry-run。
3. 构建问题先确认入口和产物格式，不要把环境警告直接当成根因。
4. 代码、测试和文档必须一起更新；命令以仓库当前脚本为准。
