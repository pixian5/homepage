# 27.1.8：构建不再退出 Safari

原 macOS 一键构建会向 Safari 发送退出命令。扩展存储快照只能保护主页数据，无法恢复无痕窗口。现在 npm 与 dist 默认入口都只生成扩展目录及 zip/xpi，不探测窗口、不生成原生工程、不改注册或已安装应用。签名体检即使发现问题也只报告，不会借定时任务重建安装。

显式原生安装命令是 `bash dist/build-macos.command --install`。只在用户明确要求、已自行退出 Safari 时使用；Safari 正在运行或无法确认进程状态时以非零状态退出，不尝试关闭它。安装前仍保留扩展数据快照与一致性校验。

验证：用临时目录和系统命令替身模拟 Safari 运行及探测错误；实际运行无参数 dist 入口生成 27.1.8 四份归档，已安装宿主仍是 27.1.7、签名摘要未变。554/554 项 Node 测试和静态检查通过。未运行真实安装或浏览器交互测试。
