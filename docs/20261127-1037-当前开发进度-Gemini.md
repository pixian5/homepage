## 本轮完成内容

### 1. 修复设置面板同步管理接口 `baseUrl` / `url` 契约失配与弹窗防重入（`src/js/sync-settings-panel.js` & `src/js/sync_http_transport.js`）
- **根因**：`applySyncSettingsFromForm()` 返回 `{ url, token }`，此前直接传给要求 `cfg.baseUrl` 的 `httpGetDevices`、`httpHealth`、`httpRetireDevice`、`httpGetSnapshots` 与 `httpRestoreSnapshot`，导致真实运行中设备列表、设备退役及云端快照操作误返回 `no_url`。
- **修复**：
  - 在 `src/js/sync-settings-panel.js` 新增 `toTransportConfig(cfg)` 统一转换为 `{ baseUrl, token }`，覆盖设备仪表盘、设备退役/恢复、快照列表与回滚及服务器连通性测试全部调用点。
  - 在 `src/js/sync_http_transport.js` 新增内部辅助函数 `syncHttpResolveBaseUrl(cfg)`（优先 `cfg.baseUrl`，兼容回退 `cfg.url`），覆盖全模块全部 9 处传输端点调用。
- **弹窗解锁与防连点**：
  - 为 `openSyncConflictModal` 的 `run(choice)` 补充 `finally` 块，失败或抛异常后立即恢复 4 枚操作按钮可点击状态；
  - 为 `#btnSyncSnapshots` 接入 `runWithButtonState`，防止慢网络下重复触发请求。

### 2. 消除内容脚本最后 1 处 `innerHTML`（Trusted Types 兼容）（`src/js/bookmark-sidebar.js`）
- 将 `src/js/bookmark-sidebar.js` 书签条目渲染的 `copy.innerHTML = ...` 替换为纯 DOM `document.createElement` + `textContent` + `append(titleEl, urlEl, pathEl)`，确保内容脚本在启用严格 Trusted Types CSP 的站点可安全运行，整个 `src/` 运行代码 `innerHTML`/`outerHTML`/`insertAdjacentHTML` 清零。

### 3. 补齐单测与同步服务端文档（`tests/` & `docs/server-sync.md`）
- 新增 `tests/sync-conflict-resolver.test.js`（5 项用例，直接覆盖 `src/js/sync_conflict_resolver.js` 无冲突、占位远端重拉 `docId` 漂移、以及 `local`/`remote`/`merge` 三分支与推送失败回写）。
- 扩展 `tests/sync-settings-panel.test.js`（校验 `refreshSyncDevices` / `httpGetSnapshots` / `httpRestoreSnapshot` 入参必含 `baseUrl`、E2EE 口令轮换校验/失败/成功流、冲突弹窗 `finally` 按钮恢复）。
- 扩展 `tests/sync-http.test.js`（集成测试 `httpGetSnapshots`、`httpRestoreSnapshot`、`{ url }` 兼容回退、空 ID 参数与 `401 unauthorized`）。
- 扩展 `tests/bookmark-sidebar.test.js`（Trusted Types 零 `innerHTML` 写入回归断言）。
- 在 `docs/server-sync.md` 补充 `/v1/sync/snapshots`、`/v1/sync/snapshots/restore` 与 `rotateE2eePassphrase` 接口文档及示例。
