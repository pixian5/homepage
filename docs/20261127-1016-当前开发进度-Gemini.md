- **`computeReclaimCandidates()` 与 `POST /v1/sync/reclaim` 密文守卫**：当云端当前状态文档为 `homepage.sync.e2ee.v1` 密文信封时，计算可回收候选集返回空数组 `[]`；`dryRun: true` 返回 `200 { ok: true, dryRun: true, encrypted: true, candidates: [], candidateCount: 0 }`；`dryRun: false` 强制执行返回 HTTP `409 { error: "reclaim_unsupported_for_e2ee", encrypted: true }`，避免破坏加密信封或误推 `epoch`。
