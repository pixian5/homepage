# 27.2.8：加固 `icon-manager` 在途去重、陈旧 URL 防护与静默标签页标题抓取

## 问题与实现

1. **修复 `src/js/icon-manager.js` 并发抓取与陈旧写回问题**：
   - **在途去重与墓碑节点跳过**：在 `createIconManager` 中维护 `_pendingIconFetches`（键为 `${nodeId}::${url}`），防止重复调用 `processPendingIconFetches()` 对同一节点触发并发重复请求；遍历待抓取节点时跳过已标记 `deletedAt` 或 `purgedAt` 的墓碑节点。
   - **陈旧 URL / 删除后防误清 `iconPending`**：`fetchFaviconInBackground` 成功或全部候选失败后重新读取目标节点，仅当节点仍存在、未删除且 `target.url === url` 时才清除 `iconPending` 并执行 `persistData()` + `render()`。
   - **静默标签页标题抓取兼容性与防重入**：提取 `callTabsApi(tabs, methodName, ...args)` 同时兼容 Chrome 回调与 Firefox/Safari Promise-only 的 `tabs.create` / `tabs.remove` 接口；在 `fetchTitleViaTab(url)` 增加 `settled` 守卫，避免超时与 `onUpdated` 竞态造成重复调用 `tabs.remove`；`fetchTitleInBackground` 回写标题前二次校验 `!target.deletedAt && !target.purgedAt && target.url === url`。
