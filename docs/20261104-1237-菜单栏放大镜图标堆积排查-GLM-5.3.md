# 菜单栏放大镜图标堆积排查（PWA 端到端测试泄漏 Chromium 孤儿进程）

- 日期：2026-11-04 12:37
- 模型：GLM-5.3
- 性质：本机环境问题排查（无源代码变更，版本号不变）
- 状态：已解决并复验

## 现象

macOS 右上角菜单栏（系统状态栏）堆积很多个放大镜图标。点击后菜单为：

- 使用 Chromium 打开搜索功能
- 自定义键盘快捷键
- 设置...

## 排查过程（可复用的方法）

1. **枚举所有状态栏图标归属进程**（需要辅助功能权限，ZCode 终端已具备）。用系统事件（System Events）遍历每个进程的 menu bar 2~6：

   ```bash
   osascript <<'EOF'
   tell application "System Events"
     set out to ""
     repeat with p in (every application process)
       repeat with mbi from 2 to 6
         try
           set mb to menu bar mbi of p
           set theItems to name of every menu bar item of mb
           if theItems is not equal to {} and theItems is not equal to missing value then
             set out to out & (name of p) & " [menu bar " & mbi & "]" & linefeed
           end if
         end try
       end repeat
     end repeat
     return out
   end tell
   EOF
   ```

   结果中出现 **4 个 "Google Chrome for Testing" 进程各挂一个状态项**（Playwright 的测试浏览器，Chromium 内核，菜单文字里的"Chromium"品牌与之吻合）。这台机器没有其它在跑的 Chromium 品牌程序（ixBrowser 的 Chromium.app 未运行；Hayaku 嫌疑也被排除——它只是注入破解工具的目录名）。

2. **列出全部主进程**：共 **7 个** `Google Chrome for Testing` 主进程（其余 3 个状态项可能是注册时序未捕获，不影响结论）：

   ```bash
   ps -axo pid,ppid,lstart,etime,command | grep "Google Chrome for Testing" | grep -vE 'Helper|--type=' | grep -v grep
   ```

   关键特征：

   - 父进程号（PPID）全部为 1 → **孤儿进程**（启动它们的测试脚本早已退出，被系统初始化进程收养）；
   - 启动时间集中在 2026-11-04 03:56:30 ~ 04:02:26（约 8.5 小时前），已持续挂机；
   - 全部带 `--headless=new`（无头模式）与 `--user-data-dir=/var/folders/.../homepage-pwa-e2e.XXXXXX/profile`；
   - 打开的地址 `http://127.0.0.1:5xxxx/index.html` 是临时测试服务器，端口早已关闭。

3. **确认归属本项目**：检查任一临时目录 `/var/folders/.../homepage-pwa-e2e.YOecSK/site/`，内容是本项目"我的首页" 26.9.0 版本的构建产物（含 `manifest.webmanifest`，即第 7 轮落地的 PWA 独立运行形态）。即：凌晨某个开发会话跑 PWA 端到端（E2E）测试时启动了 7 个 Playwright 浏览器实例，测试脚本退出时**没有关闭浏览器进程**。

## 根因

1. **泄漏**：测试脚本（临时脚本，仓库中已无 `pwa-e2e` 字样）启动 Playwright Chromium 后未在退出时调用 `browser.close()` / `context.close()`，进程变孤儿常驻。
2. **视觉表现**：Chromium 在 macOS 上即使 `--headless=new` 无头模式，也会向系统注册状态栏图标（就是那个"使用 Chromium 打开搜索功能 / 自定义键盘快捷键 / 设置..."的全局搜索快捷键状态项）。于是每个泄漏实例都在菜单栏挂一个放大镜图标，堆积成排。
3. **不是**：Spotlight（系统聚焦，正常）、Hayaku/InjectLib（注入破解工具，仅一个守护进程）、Safari 扩展注册任务（只调 pluginkit，不创建状态栏项）。

## 处理

1. 结束 7 个孤儿进程（65695、68102、70484、70829、72640、77881、80044）：

   ```bash
   kill 65695 68102 70484 70829 72640 77881 80044
   ```

   主进程退出后其 GPU/渲染器等子进程（Helper）也随之退出，已复查无残留。

2. **复验**：重新枚举状态栏，"Google Chrome for Testing" 状态项全部消失，菜单栏恢复为正常应用（1Password、Clash Party、PixPin、Dropbox、App Cleaner、AppGridMac、系统聚焦各一个）。

3. 检查 ZCode 定时自动化任务（CronList）为空，launchd 中也无端到端测试相关条目——本次是一次性会话产物，**不会自动复发**；防再发见下。

1. **测试脚本硬性收尾**：今后所有 Playwright 端到端脚本必须 `try { ... } finally { await browser.close(); await context.close(); }`，并对 SIGINT/SIGTERM 信号注册清理钩子；进程被强杀时 Playwright 不会代收尾。
