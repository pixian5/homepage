## 一、抽离 `src/js/grid-renderer.js`（314 行）

- `createGridRenderer(deps)`——十六项依赖注入（elements/数据/状态/七个 manager/打开与菜单回调）：
  - **`createTileElement(node, idx, seq, iconCache)`**：卡片 DOM（`.tile` + gridcell ARIA + 可读名）与全部事件装配——点击（触摸抑制/批量转选择/文件夹/URL 白名单/openModeMgr.openCard）、中键 auxclick 后台、键盘 Enter/空格、右键菜单、悬停 tooltip、drag-manager 与 touch-drag-manager 绑定、folder 徽标（子项数）、选中态；
  - **`renderGrid()`**：布局计算（密度表/列数/卡片尺寸自适应/移动端最小列/主网格布局缓存供覆盖层复用/`--tile-*` CSS 变量）→ **渲染批次 seq 守卫**（新批次启动后旧批次的异步图标更新作废）→ 图标缓存预加载一次共享 → 依序挂载 → 空状态；
  - **`updateEmptyState()`**：历史分组按 API 状态（error/missing/fallback/ok）四套文案与"有数据即隐藏"；普通分组仅无节点且未关闭提示时显示引导；
  - `uniqueNodes` 导出（含数组防护）；
- app.js：`renderGrid/updateEmptyState/uniqueNodes` 与 `renderSeq/lastMainLayout/MIN/MAX_TILE_SIZE` 全部删除，render() 与 reloadFromStorage 改一行 `gridRenderer.*`；
- **初始化顺序修正**（冒烟抓到的真实缺陷）：gridRenderer 的 deps 在工厂求值时捕获各 manager 实例引用，必须创建于全部 manager 之后——首版放早了导致 `dragManager` 为 null，浏览器冒烟立即暴露。
