## 本轮完成内容

### 1. 服务端 `.snapshots/` 历史快照查询与原子回滚 API（`scripts/sync-server.mjs` & `src/js/sync_http_transport.js`）
- **`GET /v1/sync/snapshots`**（Master-only）：逆序扫描 `.snapshots/` 历史滚动快照，返回 `{ id, createdAt, bytes, revision, epoch, encrypted }` 元数据列表。
- **`POST /v1/sync/snapshots/restore`**（Master-only）：
  - 校验 `confirm === "RESTORE"` 及 `isValidSnapshotId` 严格白名单校验（阻止路径穿越与非法扩展名），缺失返回 `404 snapshot_not_found`。
  - 在串行写队列内先自动转存当前线上状态快照，随后基于选中快照恢复 `doc` / `deletions` / `reclaimedIds`，递推最新 `revision = max(当前, 快照) + 1` 与 `epoch + 1`，并将各设备已确认进度清零以促使全端拉取刷新。
- **客户端传输封装**：在 `src/js/sync_http_transport.js` 新增导出 `httpGetSnapshots(cfg)` 与 `httpRestoreSnapshot(cfg, snapshotId)`。

### 2. E2EE 端到端加密口令安全轮换闭环（`src/js/sync_engine.js`）
- 新增导出 `rotateE2eePassphrase({ oldPassphrase, newPassphrase })`（运行于 `enqueue` 串行队列内）：
  - 先在不改本机口令的前提下用 `oldPassphrase` 拉取并解密合并云端最新文档（口令错误直接终止并保留本地与云端不变）；
  - 构造最新 `SyncDocument` 并显式使用 `newPassphrase` 重新加密推送至服务端（遇 `412` 自动解密重拉并重试）；
  - 云端写入成功后才更新本地 `syncE2eeEnabled = true`、`syncE2eePassphrase` 与 `_syncMeta` 落盘，本地写入失败则自动回滚设置字段。

### 3. 设置面板 UI 与 8 语言国际化（`settings-form-renderer.js`、`sync-settings-panel.js`、`app.js`、`app-i18n.js`）
- 新增 `#btnSyncRotateE2ee`（「更换口令」弹出旧/新/确认口令安全轮换弹窗）与 `#btnSyncSnapshots`（「云端快照」纯 DOM 构建列表与二次确认回滚弹窗，回滚后立即 `pullNow` 同步本机视图）。
- 设备/健康度面板新增云端加解密状态与快照计数展示；为全部 8 种语言补齐完整词条。

### 4. 新增回归单测
- `tests/sync-server-security.test.js`：补充 `GET /v1/sync/snapshots` 与 `POST /v1/sync/snapshots/restore`（鉴权、路径穿越拒绝、缺少确认词拒绝、不存在 404 及真实回滚后 revision/epoch/数据恢复）集成验证。
- `tests/sync-e2ee.test.js`：补充真实 `sync-server.mjs` 下的错误旧口令拒绝保护及正确旧口令安全轮换 E2E 校验（全量单测增至 **659/659**）。
