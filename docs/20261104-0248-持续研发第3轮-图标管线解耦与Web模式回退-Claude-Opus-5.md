## 二、独立 Web / PWA 离线模式适配

### localStorage 平滑回退（`shared-utils.js`）

- `storageArea(useSync)`：无扩展 storage 时自动返回 **localStorage 兼容层**——完整实现 `chrome.storage.StorageArea` 语义（`get` 支持 string/array/object 默认值/null 全量，`set/remove/clear`），**回调与 Promise 双签名**（与 Firefox hybrid 一致），值经 JSON 序列化；同一页面引用稳定；
- `getStorageMode()` 三态：`extension`（优先扩展存储，行为零变化）/ `web-local` / `memory`；
- `storageGet/storageSet` 空区域安全（undefined / "no_storage_area"）。

### storage.js 全部 8 处 `!api` 短路改造

loadData / loadDataFromArea / saveData / clearData / loadIconCache / flushIconCacheOnce / loadBgCache / saveBgCache 统一改为「无扩展 API **且** 无 Web 回退存储」才短路——这是 Web 模式能持久化的关键（首版只改了 loadData，E2E 抓出 saveData 短路导致所有保存被丢弃）。

### 安全降级与就绪日志

- `chrome.history.search`：history-manager 已有 missing → 自建记录回退（Web 模式下自建记录同样走 localStorage，历史分组依然可用）；
