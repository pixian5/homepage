## 二、PWA 离线闭环

### `src/manifest.webmanifest`

标准 Web App Manifest：name/short_name、`start_url: newtab.html`、`display: standalone`、theme `#1e293b` / background `#0f172a`、图标（any + maskable）；`newtab.html` 头部接入 `<link rel="manifest">` 与 `<meta name="theme-color">`；`logo.png` 进入 src（构建 rsync 自动带入三端产物）。

### `src/sw.js`（132 行，原生 Service Worker）

- **install**：预缓存 42 项核心静态资源（页面/样式/manifest/logo + 与 firefox-modules.json app 链路一致的全部前端模块）——逐项 `cache.add` 容错（单个失败不回滚整体）+ `skipWaiting`；
- **activate**：按 `homepage-pwa-` 前缀清理旧版本缓存 + `clients.claim`；
- **fetch**：同源 GET 走 **Cache-First + 后台更新（Stale-While-Revalidate）**；非 GET 与跨源（同步服务器、壁纸 API）不接管；离线导航请求回退 `newtab.html` 应用外壳；
- 版本串 `homepage-pwa-vN` 驱动缓存失效。

### 注册链路（shared-utils）

`registerServiceWorkerIfNeeded()`：扩展环境（runtime.id）/ 非安全上下文 / 无 API 三重跳过，安全上下文自动注册并打印「PWA 就绪」日志；app.js Web 模式分支调用。
