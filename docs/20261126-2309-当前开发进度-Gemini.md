# 27.2.9：闭环修复代码审查发现的同步裁剪误判、`lastError` 漏消费与多端细节缺陷

## 问题与实现

1. **修复同步落盘对 `local_trimmed_*` 降级哨兵的误判裂脑**：
   - 在 `src/js/shared-utils.js` 抽出 `isLocalTrimWarning()`，统一识别 `"local_trimmed_*"` 非阻断成功降级哨兵；
   - `src/js/sync_engine.js` 的 `persistMergedLocalState` 与 `src/js/sync_device_auth.js` 的 `ensureDevicePairing`（以及复用的 `src/js/persistence-coordinator.js`）均将 `local_trimmed_*` 视为已成功落盘，避免磁盘及 Safari 稳定存储已更新但内存被回滚或拒绝切换状态；`tests/sync-engine-write-failure.test.js` 与 `tests/sync-device-auth-unit.test.js` 补齐防回归单测。
2. **统一扩展 API 调用器并加固 `icon-manager`**：
   - 将 `src/popup.js` 中的 `callExtensionApi` 下沉至 `src/js/shared-utils.js` 供跨模块复用，`src/popup.js` 同步统一 `getCurrentTab`、`getCurrentWindowTabs` 与 `appendLog` 调用，并为内联 Toast 兜底及 `src/js/content-toast.js` 补齐无 `document.body` 保护；
   - `src/js/icon-manager.js` 的 `callTabsApi` 改走 `callExtensionApi`（正确消费 `chrome.runtime.lastError`），`fetchTitleViaTab` 新增 `tabs.onRemoved` 监听以在标签页被提前关闭时立即收尾，`fetchTitleInBackground` 补齐入口有效性与 `_pendingTitleFetches` 去重，`fetchFaviconInBackground` 在进入并发槽后二次校验节点存活，已在 `tests/icon-manager.test.js` 新增 2 项回归单测。
3. **修复 `background.js`、`popup-batch-save.js`、`storage.js`、`bookmark-sidebar.js` 与注册脚本 P2 问题**：
   - `src/js/background.js` 的 `addBookmarkToFolderInData`（及 `src/js/popup-batch-save.js` 的 `appendTabsToContainer`）对齐新节点的 `createdAt` / `updatedAt` / `titleUpdatedAt` / `urlUpdatedAt` 单调时钟，拒绝向 `deletedAt` / `purgedAt` 墓碑文件夹写入，并在消息成功响应中附带新建节点供侧栏实时刷新；
   - `src/js/storage.js` 抽出 `fallbackSyncToLocal`，修复 `useSync` 回退本地失败时遗漏回滚 `syncEnabled` 与成功时遗漏写入 Safari 稳定存储的问题；
   - `src/js/bookmark-sidebar.js` 改为按请求侧单侧渲染（消除隐藏面板的重复 DOM 与双倍图标请求）、修复目录区高度溢出的布局隐患，并在侧栏「添加书签」成功后即时刷新展示列表；
   - `scripts/safari-extension-register.sh` 增加 `is_enabled` 检测，当扩展已在册但未处于 `+` 启用态时自动执行 `pluginkit -e use`。
