# 27.2.6：网页书签侧栏过滤精确化、保存反馈闭环与快捷键支持

## 问题与实现

1. **修复网页书签侧栏文件夹过滤前缀串扰与同名文件夹串扰（`src/js/bookmark-sidebar.js`）**：
   - 在 `walk(data, lang)` 遍历书签与文件夹树时记录祖先容器 ID 链 `folderIds`（根分组 `[group.id]`，嵌套文件夹 `[...folderIds, folderId]`）。
   - 将底部文件夹树点击过滤由 `item.path.join("\u0000").startsWith(prefix)` 改为 `items.filter((item) => item.folderIds.includes(folder.id))`，彻底解决前缀重合目录（如 `AI` 与 `AI Tools`）及同名子文件夹之间的串扰。

2. **补齐网页侧栏「添加书签」跨浏览器异步消息兼容与 8 语言反馈**：
   - 在 `SIDEBAR_I18N` 全部 8 种语言（`zh-CN`、`zh-TW`、`en`、`ja`、`ko`、`de`、`fr`、`es`）补齐 `saved` 与 `saveFailed` 翻译。
   - 新增内部 `sendRuntimeMessage(payload)`，统一兼容 Chrome 回调（含 `runtime.lastError` 检查）与 Firefox/Safari Promise-only 调用（含第 2 参数校验同步抛错时回退单参数 Promise）；同时在 `sendOpen` 与 `homepage_add_bookmark_to_folder` 中复用。
   - 在侧栏增加状态提示条 `.hp-status`（`.hp-status-ok` / `.hp-status-err`），点击目标目录添加书签后立即收敛 `hp-force-open` 菜单并按后台返回显示对应 8 语言成功/失败反馈（2.6 秒自动隐藏）。

3. **补充无障碍属性与 `Escape` 快捷键关闭**：
   - 为关闭按钮补齐 `aria-label`。
   - 渲染侧栏时挂载 `document` 级 `Escape` 键监听关闭侧栏根容器，并在按钮关闭或重绘时调用 `detachKeydown()` 清理监听防止残留。
