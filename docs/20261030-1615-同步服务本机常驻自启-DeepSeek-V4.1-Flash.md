# 同步服务本机常驻：macOS LaunchAgent 自启（2026-10-30 16:15）

## 背景

`docs/20261030-1555-Safari同步错误分析-本地服务未启动-DeepSeek-V4.1-Flash.md` 查到
Safari 同步报错的根因是 `127.0.0.1:8787` 没有进程监听——重启后没人把服务拉起来。
本次把服务装成 macOS 用户级自启，彻底消灭这个手动步骤。

## 做法

新增 `scripts/setup-sync-server-macos.sh`，用 LaunchAgent（用户级，不需要 sudo）托管：

| 项 | 值 |
|---|---|
| Label | `com.aeroluna.homepage.sync-server` |
| plist | `~/Library/LaunchAgents/com.aeroluna.homepage.sync-server.plist` |
| 启动时机 | `RunAtLoad` 登录即起 |
| 自愈 | `KeepAlive=true`，进程退出就重拉；`ThrottleInterval=10` 防止疯狂重启 |
| 监听 | **`127.0.0.1:8787`**（只回环，不对局域网暴露；要局域网访问设 `SYNC_HOST=0.0.0.0`） |
| node | 安装时解析成绝对路径写死，优先 Homebrew → nvm 最高版本 → PATH |
| 日志 | `~/Library/Logs/homepage-sync/server.log` / `server.err.log` |

`ProcessType=Background` 让系统按后台任务调度，不参与前台优先级竞争。

## 用法

```bash
bash scripts/setup-sync-server-macos.sh install      # 安装并立刻启动（幂等，可重复跑）
bash scripts/setup-sync-server-macos.sh status       # 加载状态、node 路径、PID、端口、健康、内存
bash scripts/setup-sync-server-macos.sh restart      # 重启
bash scripts/setup-sync-server-macos.sh logs         # 跟踪日志
bash scripts/setup-sync-server-macos.sh uninstall     # 停止并移除自启（日志保留）
bash scripts/setup-sync-server-macos.sh install --dry-run   # 只打印将要写入的 plist
```

可覆盖的环境变量：`SYNC_PORT` / `SYNC_HOST` / `NODE_BIN` / `SYNC_TOKEN`。

`install` 内置三道自检：plist `plutil -lint`、启动后 10 秒内轮询 `/health`、
`status` 会校验 plist 里写死的 node 路径是否还存在（nvm 删版本时会提示重新 install）。

## 实测结果

### 功能

- 安装后 `launchctl print` 显示 `state = running`，端口 `127.0.0.1:8787`，`/health` 200。
- **崩溃自愈**：`kill -9` 掉进程后 4 秒内自动拉起，PID 从 86433 变为 88308，`/health` 仍 200。
- **同步恢复**：服务起来后扩展自动完成一次推拉，
  `homepage_sync_state` 由 `status=error / lastError=Load failed` 变为
  `status=idle / lastError 空`，`lastRemoteRevision` 从 12 走到 15，`lastPullAt/lastPushAt = 16:10:40`。

### 资源占用（修正此前口径）

| 指标 | 实测 |
|---|---|
| 物理内存 RSS | **约 42 MB**（刚启动 50 MB，稳定后 42 MB） |
| CPU | **0.0%**（空闲；累计 CPU 时间几乎不增长） |
| 磁盘 | `data/homepage-sync-state.json` 约 34 KB |
| 网络 | 仅本机回环，每次同步几十 KB |

> 更正：先前口头说的「10.7 MB」是取样偏差（进程刚 fork 时 RSS 未涨满）。
> 用同样方式分别跑 node 22 / node 24 对照，两者都在 57–64 MB 起步，
> 稳定后 42 MB，所以按 **40–50 MB** 记才准确。

## 已知边界

- 这是**用户级** Agent：只在该用户登录后运行；机器重启但没人登录时不会起。
  需要开机即起（未登录也跑）得装 LaunchDaemon，但那就涉及系统级权限，且本项目数据在用户目录，没必要。
- `KeepAlive=true` 意味着手动 `kill` 也会被拉起；要停就用 `uninstall`。
- node 路径是安装时写死的绝对路径。**升级或删除 nvm 版本后要重跑 `install`**，
  否则 launchd 会反复失败（`status` 会直接标出「不存在！」）。
- 日志不做自动轮转。当前量级极小（每次启动几行），需要时手动清 `~/Library/Logs/homepage-sync/`。

## 验证命令
