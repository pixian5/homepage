## 变更内容

### 1. 进程级终止信号守护（根治泄漏机制）

`tests/helpers/browser-process.js` 新增导出 `trackChildShutdown(child)`：

- 内部维护已登记子进程集合，首次调用时安装一次性的 SIGINT / SIGTERM / SIGHUP 处理器；
- 测试进程收到终止信号（Ctrl+C、CI 超时强停等）时，`finally` 不会执行——处理器先逐个 `stopBrowser`（复用现有进程组 SIGTERM→SIGKILL 兜底逻辑，自带超时），完成后重放原信号恢复默认终止行为（保留 CI 对退出码的判断）；
- 第二次信号到达时不再等待清理，立即终止（连按 Ctrl+C 可强退）；
- 子进程正常退出自动注销；Windows 上保持无操作（no-op）；
- 幂等，可对同一子进程重复登记。

### 2. 残留清扫脚本 `scripts/cleanup-e2e-leftovers.sh`（新增）

- 结束**孤儿测试进程**：仅限 PPID=1（父进程已死被系统收养）且命令行带本仓库测试临时目录前缀特征串（`homepage-pwa-e2e.` / `homepage-browser-sync-e2e.` / `homepage-smoke-` / `homepage-firefox-persist-` / `homepage-firefox-sync-`）；SIGTERM 优雅结束，2 秒后对顽固者 SIGKILL；
- 删除系统临时目录（TMPDIR）下各端到端脚本的遗留目录（含历史泄漏的 `homepage-pwa-e2e.*`）；
- 安全设计：正在运行的测试其浏览器父进程（node）还活着、PPID 不为 1，**不会被误杀**；不按浏览器二进制名匹配，不误伤日常浏览器；
- 兼容 macOS 自带 bash 3.2（无 mapfile / 关联数组）；进程快照先行，避免 ps 管道把自身命令行误当目标。

### 3. `scripts/run-all-smoke.sh` 接入

回归流程从 4 步扩为 5 步：新增"0/5 清扫上次端到端测试残留"，每次全量回归前自动清掉历史泄漏。

### 4. 回归测试（`tests/browser-process.test.js` 新增 2 项）

1. **信号守护端到端**：宿主进程登记 detached 子进程后收到 SIGTERM → 宿主按原信号退出，孙进程被一并结束（模拟 2026-11-04 事故场景）；
2. **幂等与注销**：重复登记同一子进程不抛错、返回原对象，正常退出后再调用无副作用。

## 遗留说明

- `run-browser-smoke.mjs` 历史上以 `bash -c` 单命令方式手工复现泄漏时，发现 bash 会对单条命令做可执行文件替换（exec）优化导致 `$0` 特征串丢失——清扫脚本按**临时目录特征串**而非进程名匹配，不受此影响；
- 泄漏的原始脚本（凌晨会话的 PWA 端到端临时脚本）已不在仓库中，无迹可修；本轮防护覆盖仓库内全部现存端到端脚本。
